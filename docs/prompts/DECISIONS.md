When Craig replies, the agent pastes the reply verbatim, sets `DECIDED`, and cites the id in the ledger row or handoff that depended on it. `npm run agents:check` rejects a row without a recommendation, a status other than OPEN or DECIDED, or DECIDED without a reply. **Blocks** names what cannot proceed while the row is OPEN; `entry <N>` is machine-read, so `npm run agents:check -- --entry <N>` fails until Craig answers.

Reply in chat with the ids, for example: `D-013 approved. D-014 no.` Or delegate: say which decisions the seats may decide; the panel named in the row decides blind (`docs/prompts/seats/DECISION_FORMAT.md`), `npm run agents:decisions` tallies it, and this row records your delegation and the result.
