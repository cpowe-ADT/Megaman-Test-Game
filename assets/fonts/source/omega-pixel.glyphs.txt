# OmegaPixel: an original pixel font for OMEGA Relay (part 12i, EVAL-P8-003). Drawn here as data;
# scripts/fonts/build-pixel-font.py builds assets/fonts/omega-pixel.woff (Phaser Text) and
# assets/fonts/omega-pixel.png + .xml (BMFont, the HUD's 'font' key) from this file.
#
# Each glyph is a header "U+XXXX <char>" followed by exactly 8 rows of '#' (ink) and '.' (blank).
# Row 0 holds accents, rows 1-5 are the cap height (the baseline is under row 5), rows 6-7 hold
# descenders. The row width is the glyph width; the advance adds one blank column. The em is 8 rows,
# so 8px, 16px and 24px put every font pixel on whole game pixels.
# Coverage: ASCII 32-126, the symbols the UI prints (· • − × … — ● ○ →, with ← ↑ ↓ for symmetry) and
# É, which Phaser's text metrics string ("|MÉqgy") needs so line heights never come from a fallback font.
